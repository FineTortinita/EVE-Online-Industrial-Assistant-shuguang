# 物品查询

查询页用来**搜一件物品、看它的价格和行情**。它有两种样子，什么时候显示哪一种，全看「**当前有没有选中物品**」：

- **没选** → 显示**空闲态仪表盘**（产线详情 / 资产折线图 / 挂单列表）
- **选中了** → 显示**详情面板**（5 个贸易中心价格 / 订单 / 精炼 / 制造材料）

所以这个页面既是「查价工具」，也是你**打开软件后的第一屏** —— 不选物品的时候，它就当仪表盘用。

## 搜物品

1. 顶部搜索框输入**名称或 ID**，边打字边出候选清单
2. **点候选里的那一条** —— 详情面板立刻换成这件物品的数据（回车 = 选第一条）

> 💡 **候选清单就是全部匹配**，条数不限、不够高时自带滚动条。不用先「搜索」再挑：
> 选中一条即出详情。
>
> 💡 名字按**开头**匹配：输入 `gila` 会出 `Gila`、`Gila Blueprint`、`Gila Hostile Takeover SKIN`……
> 但不会出名字中间含 gila 的其它物品。数字则按 **Type ID 精确**匹配。
> （按类别找物品请点「全物品」，那里有分类树。）

工具栏上还有几个按钮：

| 按钮 | 作用 |
|------|------|
| 全物品 | 打开全物品浏览器（内嵌面板），按类别翻 |
| 清空 | 清掉当前选中，回到空闲态仪表盘 |
| LP 兑换 | 打开「LP 兑换价值」窗口：选 NPC 公司，按所选贸易中心卖价计算每个兑换项的利润与每 LP 收益（见下文） |
| 行星加工 | 打开「行星加工利润」窗口：68 条行星加工配方按每小时利润排序，含海关税（见下文） |
| 区域（右上角下拉）| 换查询 / 详情用的贸易中心 |

> 2026-10-17 起「批量查价」「制造配方」入口与「价格走势图」对话框已移除（无生产入口的死链清理）；
> 全物品改为内嵌面板，双击物品进入详情。

> 💡 搜索框空着的时候**点一下它**，就会把你搜过的历史列出来；
> 点历史里的词 = 把它填回搜索框并重新列出候选（历史里是词，不是某一件具体物品）。

## 选中之后：详情面板

选中一件物品后，主区域是**四块面板**（左上 / 右上 / 左下 / 右下）：

- **左上 · 5 个默认贸易中心的价格**：Jita / Amarr / Dodixie / Rens / Hek 挨个列出买单卖单价，
  带柱形条，左侧的小圆点表示该中心属于哪个帝国。**最便宜 / 最贵**的那一格会标出来。
- **右上 · 订单列表**：实时从 ESI 拉的最优订单，**卖单和买单分两列**，
  每边上各有一个「复制最优价」按钮，点一下就把价格抄进剪贴板。
- **左下 · 精炼产物、价格**：这件物品拆掉能出什么矿、各值多少，底部给总计与利润。
  **产率按所选人物的提炼技能算** —— 顶部可以选**人物**、填**数量**、选**站点**
  （NPC 空间站 / 玩家设施），三者任一改动都会重算。
  人物技能在「人物设置 → 精炼」里填（`提炼学概论` / `提炼效率理论`）；没填就按 0 级算。
  不能精炼的物品会写明「该物品不可精炼」。
  **按批精炼**：矿石要凑够一批才精炼（凡晶石等多数矿石 100 单位一批），选中物品时数量默认填一批；
  不足一批的余量不精炼也不计入投入，面板下方会写「每 100 单位一批，共 N 批，余 M 单位不精炼」。
  总计行的 **「每方」** = 每立方米矿石精炼后值多少 ISK，用来按货舱容积比较哪种矿最值得挖 / 运。
- **右下 · 制造所需的材料**：造它要哪些料、各值多少。上面有**制造数量**输入框和
  **价格中心**下拉框 —— 改这两个，整张表跟着重算；底部给按卖价 / 买价算的合计。

## 没搜的时候：仪表盘

不查东西时，主区域是三块横排的面板。

### 产线详情

**每个人物一块**，块里**制造 / 科研 / 反应各一行**：

- 每行一条容量条，行尾是「已用 / 上限」。格子点亮 = 那条产线在跑。
- 行尾还可能有两个小提示：
  - **待下线 N**（橙色）—— 这个人物在这类产线里有 N 条**可下线**的计划
  - 条子长度按**所有人的共同分母**画，所以不同人物的条子长短可以直接比
- 人物多的时候这一栏自己**滚动**；面板太窄、格子画不清时会降级成一条按占用比例填充的整条
  （信息不丢，把鼠标停在行上能看到逐行数字）。

> 想**启动 / 下线**产线，请去「生产计划表」或「产线启动小助手」——
> 仪表盘上原先那块「快捷操作」列表已经删掉了。

### 资产折线图

五条线，各代表一项资产：

| 线 | 含义 |
|----|------|
| 总资产 | 下面四项之和 |
| 挂单金额 | 你所有挂单的当前价值 |
| 库存材料 | 各机库材料按卖单价估值 |
| 运行中产线价值 | **制造中**产线占用的材料（按计划的完整材料需求算，含还缺的那部分）× 卖单价。科研 / 反应 / 拷贝不计入 |
| 钱包余额 | 你自己填的数字（见下），订单成交会自动加减 |

- **点底部的图例**可切换某条线的显示 / 隐藏（至少留一条）。
  隐藏后纵轴刻度会跟着剩下的线变 —— 免得被数量级大的那条压成一条直线。
- **时间跨度**四档：近 7 天 / 本月 / 本年 / 总。
- 上面的「资产（表格显示）」列出各线最新值，以及相对**区间起点**涨跌了多少。
- 右上角的 **「刷新」** 按钮会立刻重读一遍数据（平时是每 60 秒自动刷一次）。

> ⚠️ **数据从你第一次记录那天开始按天累积** —— 刚开始只有零星几个点，
> 不是坏了。导入一次挂单、或者填一次钱包余额，就把今天这一天记下来了。

### 挂单列表

这块管的是你**游戏里的挂单**，数据来自你从游戏里导出的文件。

**怎么用（三步）：**

1. 进游戏，打开 **钱包 → 订单**，点**导出**按钮 —— 游戏会在
   `我的文档\EVE\logs\Marketlogs\` 写一个文件（国服文件名形如
   `个人订单-2026.09.16 1232.txt`）。
2. 回到软件，点面板上的 **「读取订单」**。它会自动找那个目录里**最新**的一份来读。
   （目录是固定的，不用也不能在界面里改。）
3. 读进来后，列表**分成上下两块**：上面是**买单**、下面是**卖单**，
   各自显示**物品 / 价格 / 剩余·总量 / 位置**，每块标题上有笔数，底部给汇总。

**被压单提醒（改单价）**：「位次」列把每笔挂单和该市场的最优价比（点「刷新行情」用实时价）。
被别人压了价的显示为红色「不在首位」，并在后面给出**抢回首位的改单价**，如
`不在首位（最优 1,234.00）→ 改 1,233.00`；底部汇总会写「被压单 N 笔」。
**双击那一行**就把改单价复制到剪贴板，回游戏改单窗口直接粘贴。
改单价遵守游戏「挂单价最多 4 位有效数字」的规则（曙光实时挂单实测验证），所以 1,234 被压时给的是
1,233 而不是 1,233.99（后者游戏不接受）。首位 / 并列最优 / 无法判定的行双击不做任何事。

**读完会弹一个「确认订单变动」框**（有变动时才弹），逐条列出这次导出里**消失的**或
**数量变少的**订单，每条让你选：

| 选什么 | 什么意思 | 钱包怎么变 |
|--------|----------|-----------|
| **买到了 / 卖完了**（默认） | 这笔在游戏里成交了 | 卖单 **+** 价格 × 数量，买单 **−** 价格 × 数量 |
| **手动撤销** | 是你自己在游戏里撤的单 | 不动钱包 |

点「应用变动」后，软件就按你的选择**加减钱包余额**、把结束掉的挂单从列表里去掉
（部分成交的留下、数量改成成交后剩下的），并重记一条资产快照；点「取消」则什么都不做。

> 💡 变动金额**不扣销售税 / 中介费** —— 那份手续费在游戏里已经各自结掉了，
> 这里只记挂单本身的成交金额。

**钱包余额**：也可以**手填**（游戏导出文件里没有它）。在
「钱包余额」框里填当前 ISK（可带千分位，如 `1,234,567.89`），点「记录」。
它会存进设置、并记一条资产快照，参与上面的折线图；订单成交的加减都记在这同一个数上。

**不想手打**就用面板上的 **「从剪贴板导入」**：在游戏「钱包 → 交易记录」里 `Ctrl+A` /
`Ctrl+C` 复制，再点这个按钮。软件取**最新一笔的余额**（那一列是逐笔累计后的实时余额）
当钱包余额记进去 —— 与点「记录」是同一件事。

> 💡 反复导入同一份文件是**幂等**的 —— 用订单 ID 去重，不会越读越多，
> 也不会重复提示变动。挂单金额、库存材料和运行中产线价值，每次「读取订单」或
> 「记录钱包余额」时都会跟着重新记一遍。

## LP 兑换价值

工具栏「LP 兑换」打开独立窗口，用来挑「拿 LP 换什么最赚」：

1. **公司**：选 NPC 公司（默认加达里海军），兑换项实时取自曙光官方接口，公司名为中文。
2. **价格中心**：默认索巴色基，可切换其它贸易中心；价格读本地已更新的市场数据。
3. 表格按 **ISK/LP** 从高到低排列：

   每 LP 收益 =（兑换数量 × 卖价 − 星币成本 − 所需物品 × 卖价）÷ LP 成本

- **卖单挂量**标黄：当前卖单数量少于一次兑换的产出，按这个价格不一定卖得掉，先看盘口再换。
- 显示「缺价」：兑换物品或所需物品在该中心没有价格，不按 0 成本估算。
- 结果**未扣销售税与经纪人费**，只用于排序比较。
- 提示「本地还没有索巴色基的价格」：在顶栏「区域」勾选 Sobaseki 后点「更新价格」。

## 行星加工利润

工具栏「行星加工」打开独立窗口，用来挑「买原料加工再卖」哪条行星加工链最赚：

- 配方取自曙光客户端（68 条，P0→P1 到 P3→P4），周期与曙光官方接口一致。
- 每行：产物、层级、周期、每周期原料、产出数量、收入、原料成本、海关税、每周期 / 每小时利润、利润率；按**每小时利润**从高到低排。
- 顶栏可选**层级**（P1–P4）、**价格中心**（默认索巴色基）、**海关税率**（默认 10%，即高安 NPC 基础税率；玩家海关按实际税率填）。
- **海关税**：产物出口按「计税基准 × 税率」，原料进口按半价；计税基准 P0 5 / P1 400 / P2 7,200 / P3 60,000 / P4 1,200,000 ISK。原料在本星球自产时取消勾选「原料经海关进口」，只算出口税。
- 原料与产物都按卖单价计，未扣销售税与经纪人费；缺价的行显示「缺价」，不按 0 计。
- 这是加工利润，不模拟提取器产量、殖民地布局与 CPU/电网。

## 常见问题

- **「读取订单」说没找到文件？** 先确认游戏里点过导出，再看文件是不是落在
  `我的文档\EVE\logs\Marketlogs\`、文件名是不是含 `order` 或 `订单`。
- **资产折线图是空的？** 还没记过任何快照 —— 导入一次挂单或填一次钱包余额即可。
- **订单列表的「物品」列是空的？** 不会 —— 软件会用 Type ID 去 SDE 补中文名；
  真缺了说明本地 SDE 数据没导全（跑一次数据初始化）。
- **钱包余额对不上？** 它 = 你手填 / 上次记录的数值 + 你在变动框里确认过的成交金额。
  如果某笔你判成了「手动撤销」，它的金额就不会入账。
